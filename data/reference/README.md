# Real-data visual reference

`maxi_j1820p070_mjd58302.csv` is a background-subtracted MAXI/GSC
count-rate-density spectrum of the real black-hole X-ray binary MAXI J1820+070.
It covers MJD 58301.5-58302.5, overlapping EvoXRB's synthetic E08 anchor at MJD
58302.1.

The source spectrum, background spectrum and response were generated by the
[RIKEN/JAXA MAXI on-demand process](https://maxi.riken.jp/mxondem/api/results/20260828013000_evoxrbv020real01/index.html).
The exact submitted configuration is retained alongside the CSV. The 1,200
native PHA channels were grouped into 0.5 keV display bins from 2-10 keV using
the response EBOUNDS table. Background counts were scaled with the OGIP
exposure and `BACKSCAL` values before subtraction. Statistical display errors
propagate source and scaled-background Poisson counts.

Recreate the CSV after downloading and extracting the result's spectrum archive:

```powershell
python scripts/prepare_maxi_reference.py --source path/to/MAXI_J1820p070_MJD58302_gsc.pi.gz --background path/to/MAXI_J1820p070_MJD58302_gsc_bgd.pi.gz --response path/to/MAXI_J1820p070_MJD58302_gsc.rmf.gz --output data/reference/maxi_j1820p070_mjd58302.csv --provenance data/reference/maxi_j1820p070_mjd58302.provenance.json
```

This is a cross-instrument visual reference. MAXI/GSC count-rate density is not
numerically interchangeable with the synthetic NICER-inspired detector rate,
and the MAXI points are never included in EvoXRB's C-statistic. A physical fit
would need to use the MAXI response and background in a matching forward model.

Required acknowledgement: "This research has made use of MAXI data provided by
RIKEN, JAXA and the MAXI team." See Matsuoka et al. (2009), PASJ 61, 999.
